# Livenote Two

## Objective
Create database-driven notes application with authentication using Laravel and Livewire.

## Structure
This project has been broken into six parts. Each part will build onto the previous part and will introduce a new feature of Laravel or Livewire. 

### Part 1: Blade
Part 1 will introduce Blade layouts and components for improved reusability and management of the code.

### Part 2: Livewire
Part 2 will introduce Livewire components, properties, and actions. The web application will also be refactored to be more reactive. 

### Part 3: Component Communication
Part 3 will introduce Livewire component communicate through the use of events.

### Part 4: Databases and Models
Part 4 will introduce database management and Laravel models, and new features will be added to the web application.

### Part 5: Data Manipulation
Part 5 will introduce database manipulation and relationships allowing for the retrieval of data across multiple database tables.

### Part 6: Authentication and Validation
Part 6 will introduce Laravel authentication and validation. The ability to login and logout will be added to the web application.
